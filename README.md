# Sales Analytics — PostgreSQL & Power BI

An end-to-end sales analytics project using a modified Kaggle dataset.

## Workflow

**Kaggle Dataset → Data Preparation → PostgreSQL Database → SQL Analysis → Power BI Dashboard**

## Tools
PostgreSQL
SQL
Power BI
CSV

## Project Highlights
Structured a flat sales dataset into a relational database.
Performed business-focused sales, product, supplier, customer, regional, and profitability analysis using SQL.
Developed an interactive Power BI dashboard for business performance reporting.

## Files
Documentation.pdf — Project documentation
Dataset_Modified.csv — Prepared dataset
Database_Creation.sql — PostgreSQL database implementation
Analysis_Queries.sql — SQL analysis queries
PowerBI_Dashboard.pdf — Dashboard output

**Note**: The project is intended as a portfolio demonstration of an end-to-end business analytics workflow.
