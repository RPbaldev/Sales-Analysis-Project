# India-Japan SQL Project

## Overview
This project analyzes India-Japan trade patterns using SQL queries. It includes data cleaning, transformation, and analytical queries to extract business insights.

## Files
- 01_create_tables.sql → Database schema setup
- 02_data_cleaning.sql → Data cleaning and preprocessing
- 03_analysis_queries.sql → Analytical SQL queries

## Tools Used
- SQL
- PostgreSQL
- Visual Studio Code
- Git & GitHub

## Purpose
To practice real-world SQL data analysis and build a portfolio project for data/business roles.
